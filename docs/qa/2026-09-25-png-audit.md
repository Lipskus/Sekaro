## Palette basis and inconsistent references

The supplied archive includes different visual generations. For example, the template board 037 has a 250px sidebar while final campaign board 063 has a 216px sidebar at the same 1600px image width. Their palettes also differ. A single shared shell cannot simultaneously be pixel-identical to both. This change uses the final repeated palette from 063–096; shell geometry still needs a rendered review and a documented canonical choice. It does not claim all references are mutually identical.
