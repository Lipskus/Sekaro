# P0 — macierz 98 referencji

Wszystkie 98 plików z właściwego archiwum zostało sprawdzonych pod względem tożsamości (SHA-256) oraz obejrzanych w planszach zbiorczych. Porównano układ z renderami istniejących przepływów i kodem. To przegląd struktury i zachowania, **nie pixel-perfect QA**. Każdy wiersz ma rzeczywisty zrzut Dark/Light odpowiadającego widoku; część wcześniejszych dowodów jest w DE. Zrzuty używają danych QA, nie danych instalacji.

Klasyfikacja opisuje całą planszę: nie oznaczamy jej jako zgodnej, jeśli zawiera choćby istotną różnicę układu lub nieobsługiwany panel. Naprawione elementy opisano w uwagach. „Element przyszłego etapu” wskazuje zależność już opisaną w planie i raporcie braków backendu, nie zamawia nowej funkcji ani nie przesuwa pozostałych poprawek P0. **Odstępstwa nie są automatycznie zaakceptowane.**

Plansze stanów wymagają odczytu razem z manifestem `evidence-2026-09-30/final-states/ui-matrix.json` i testami komponentów. Zrzut podstawowy przy wierszu nie dowodzi każdego stanu na planszy. Tablice z empty/loading/error/success nie są traktowane jako jednoczesny ekran aplikacji.
